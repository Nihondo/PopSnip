# PopSnip

PopSnip は、テキストスニペットを登録し、グローバルショートカットでどのアプリにも挿入できる、macOSのメニューバー常駐アプリです。Raycast風の検索パネルで、日常使うテンプレート文をすばやく呼び出せます。

## 特徴

- **グローバルショートカットで開く検索パネル** — ショートカット（既定 `⌥⌘Space`）を押すと、どこからでもマウスカーソル付近に検索ボックスが開く
- **高速な検索** — 入力に応じてタイトル・本文のヒット箇所がハイライトされる。検索結果は関連度・使用回数・更新日時で並び替え可能
- **タグ閲覧** — 検索ボックスが空の状態では、色付きのタグチップでスニペットが分類され、ドリルダウンして絞り込める
- **ワンキー挿入** — 選択したスニペットは、直前までフォーカスしていたテキスト欄へ直接挿入される（Accessibility API、失敗時はクリップボード経由に自動フォールバック）
- **キーボード操作中心** — 矢印キーで移動、Enterで挿入、`⌘1`〜`⌘9`で直接選択、Backspaceでタグの絞り込みを1段階戻す、Escで閉じる
- 検索パネル上で**右クリックして編集・削除**が可能
- **リサイズ可能なパネル** — 最後に変更したサイズを記憶する
- **スニペット一覧ウインドウ** — 全件の一覧・絞り込み、タグの一括編集、タグ管理（名称変更・色変更・削除）
- **フォントサイズ調整**（小・中・大）— パネルと一覧に適用
- **macOS標準デザインの設定画面** — サイドバーで「一般」「パネル表示」「ショートカット」「権限」「アップデート」を切り替え
- **Sparkleによる自動アップデート確認**

## 動作環境

- macOS 14.0 以降
- アクセシビリティ権限（他アプリのフォーカス中の入力欄へテキストを挿入するために必要）

## ソースからのビルド

PopSnip の Xcode プロジェクトは、`project.yml` から [XcodeGen](https://github.com/yonaskolb/XcodeGen) で生成します。

```bash
brew install xcodegen
xcodegen generate
open PopSnip.xcodeproj
```

Xcode で `PopSnip` スキームをビルド・実行します（`⌘R`）。

## はじめかた

1. PopSnip を起動します。メニューバーのアイコンとしてのみ常駐し、Dockアイコンや初期ウインドウはありません。
2. プロンプトが表示されたらアクセシビリティ権限を許可するか、**設定 → 権限** から許可します。
3. `⌥⌘Space`（または設定したショートカット）で検索パネルを開きます。
4. 入力して検索するか、ボックスを空のままタグや最近使用したスニペットを閲覧します。
5. Enter を押すか結果をクリックすると、それまで入力していた欄へ挿入されます。
6. **登録** をクリックすると新規スニペットを作成できます。他アプリでテキストを選択していた場合、その内容が本文に自動で入力されます。
7. パネル上のスニペットを右クリックすると、編集・削除できます。

## 使い方

### 検索パネル

- 設定したショートカット（既定 `⌥⌘Space`）で開閉します。パネルは既定でマウスカーソル付近に表示されます（画面中央表示への切り替えも可能）。
- 入力すると、タイトル・本文・タグ名を横断して検索し、ヒット箇所がハイライトされます。
- `↑` / `↓` で選択移動、`Enter` で挿入、`Esc` で閉じます。
- `⌘1`〜`⌘9` でリスト内の位置を直接指定して挿入できます（**設定 → パネル表示** でON/OFF切り替え）。
- 検索ボックスが空の状態で `Backspace` を押すと、タグの絞り込みを1段階だけ戻します。
- スニペットを右クリックすると **編集** / **削除** ができます。
- パネルの端をドラッグするとリサイズでき、次回もそのサイズで開きます。
- パネル下部には **登録**・**一覧**・**設定** ボタンがあります。

### タグ

- 1つのスニペットに複数のタグを付与でき、色付きの角丸チップで表示されます。
- 新規タグには自動で色が割り当てられます。タグ管理画面の色の丸をクリックすると、パレットから別の色を選べます。
- 検索ボックスが空の状態では、パネル上部にタグ一覧が表示されます。クリックすると、そのタグを含むスニペットへドリルダウンします。
- スニペット編集中にタグを追加・新規作成できるほか、スニペット一覧ウインドウのサイドバーで全タグの名称変更・色変更・削除・新規追加を行えます。

### スニペット一覧ウインドウ

パネルの **一覧** ボタン、またはメニューバーから開きます。

- すべてのスニペットを表形式で閲覧・絞り込みできます。
- 複数行を選択し、**タグ** ボタンでタグチップをクリックして一括付与・削除できます。
- 行をダブルクリック、または右クリック→**編集** で編集画面を開けます。
- 選択したスニペットを一括削除できます。

### 設定

パネルの **設定** ボタン、またはメニューバーの **PopSnip 設定...** から開きます。サイドバーで以下を切り替えます。

- **一般** — ログイン時起動、挿入方式（自動 / Accessibility APIのみ / クリップボードのみ）、クリップボード復元待機時間、フォントサイズ、スニペットの保存先。
- **パネル表示** — 表示するセクションと並び順、表示件数、検索結果の並び順、パネルの表示位置、Enterキーの動作、数字キー選択、タグ色の表示。
- **ショートカット** — 各アクションのグローバルショートカットをカスタマイズ。
- **権限** — アクセシビリティ権限の確認・許可。
- **アップデート** — 今すぐアップデートを確認、自動確認のON/OFF、現在のバージョンの確認。

### メニューバー

メニューバーのアイコンをクリックすると、以下にすぐアクセスできます。

- スニペットパネルを開く...
- スニペット一覧を開く...
- アップデートを確認...
- PopSnip 設定...
- PopSnip について...
- 終了

## データの保存先

スニペットとタグは `~/Library/Application Support/PopSnip/snippets.json` にJSON形式で保存されます（保存先は **設定 → 一般** で変更可能）。このファイルを外部から編集した場合も、次にパネルを開いたときに最新の内容が反映されます。

## アップデート

PopSnip は [Sparkle](https://sparkle-project.org) により自動でアップデートを確認します。メニューバーまたは **設定 → アップデート** から手動で確認することもできます。
